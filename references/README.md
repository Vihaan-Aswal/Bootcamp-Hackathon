# Source materials

`requirements/` contains copies of the two supplied hackathon PDFs:

- `RADIX_Talent_Match_Hackathon_Brief.pdf` — product, role and evaluation requirements.
- `TGL_Blitz_Event_Plan.pdf` — event plan and team expectations.

Use them as the source documents for the product. The decisions and implementation
interpretation for this fresh project are recorded in the local-only `prd.md` and
`implementation_plan.md` at the repository root; those planning files are intentionally kept
out of Git, so read them in the working copy rather than on GitHub. The separate bootcamp app
and its code were not copied here.

`milestones/` contains the supplied `RADIX_Talent_Match_Milestone_Checklist.xlsx`. It defines 20 milestones across pre-work and phases 1–4; use it as the progress tracker. The implementation plan includes a readable copy of the milestone definitions.
