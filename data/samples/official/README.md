# Official sample inputs

This folder contains the official sample pack unchanged: six job descriptions and four resumes, each supplied as PDF and DOCX. Keep the original filenames and subfolders (`JDs/` and `Resumes/`). These are the evaluation inputs for the parser milestones.

The ignored local file `MANIFEST.local.md` records exact filenames, formats and hashes without committing resume names. Resume files are intentionally ignored by Git. Do not send their contents to an LLM until the selected provider’s current terms, user consent and the PRD’s privacy requirements have been checked.
